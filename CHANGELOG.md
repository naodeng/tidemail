# Changelog

## 0.1.0 - 2026-10-15

### Features

- Launch tidemail as a streamlined temporary email service with configurable mailbox domains, inbox management, and optional authorized outbound mail.
- Add seven-day message retention with scheduled cleanup, optional site password and Cloudflare Turnstile, English and Simplified Chinese, and system, light, and dark themes.
- Add centralized settings with language and theme preferences, application version, and GPL-3.0-only license information.

### Documentation

- Document Cloudflare Worker and D1 setup, deployment, and migration impact.
