# Changelog

## 0.2.0 - 2026-10-16

### Features

- Refresh the site experience with responsive layouts and interactions for phones, tablets, and desktops.
- Localize the Privacy Policy and Terms of Service in English and Simplified Chinese, with disclosures updated for the current service.

### Fixes

- Keep cached inbox messages visible with a non-blocking notice when a refresh fails.
- Correct settings menu placement and improve navigation, dialogs, and form controls across screen sizes.
- Remove two unused external links from the interface.

### Documentation

- Add an optimized project social preview image and update the README previews.

## 0.1.0 - 2026-10-15

### Features

- Launch tidemail as a streamlined temporary email service with configurable mailbox domains, inbox management, and optional authorized outbound mail.
- Add seven-day message retention with scheduled cleanup, optional site password and Cloudflare Turnstile, English and Simplified Chinese, and system, light, and dark themes.
- Add centralized settings with language and theme preferences, application version, and GPL-3.0-only license information.

### Documentation

- Document Cloudflare Worker and D1 setup, deployment, and migration impact.
